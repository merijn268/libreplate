# LibrePlate

A free and open-source food tracker and meal planner.

LibrePlate exists because many existing food tracking services are closed source, app-only, have limited features, or lock users into their platform. This project aims to provide a modern, feature-rich, configurable, and transparent alternative that anyone can use, self-host, and contribute to.

## Getting Started

LibrePlate uses invoke to manage everything from dev tools to installing. See the manual for the tasks here: [Invoke Task Manual](tasks_manual.md).

### Configuration

The server needs an `.env` file to be configured in the root directory. This can be coppied over from the `.env_example`. Read the instructions in the file
on how to configure it further.

```
cp .env_example .env
```
